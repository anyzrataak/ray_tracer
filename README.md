# Ray Tracer Project

This repository features a highly optimized C++ 3D Ray Tracer built on top of the SDL3 framework. The software architecture strictly adheres to modern object-oriented programming standards, isolating core engine logic from platform-dependent rendering layers to provide a model structure for academic and professional reference.

## Technical Specifications
- language: C++
- additional library: SDL3

## Running the Pre-compiled Binary (Recommended)
For immediate execution without manual compilation, a stable production build is provided in the project's release assets:
1. Navigate to the deployment directory containing the compiled executable.
2. Ensure that 'SDL3.dll' resides in the same directory as the `Project1.exe` file.
3. Launch 'RT_KP.exe' directly to initialize the rendering pipeline.

## Current Features
- SDL3 window initialization and event handling.
- Vector mathematics and ray-primitive intersection logic.
- Basic primitive rendering.
